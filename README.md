# Fluxos do FIDC

Simulação interativa e hipotética dos fluxos de um FIDC, com comparação entre partes independentes e Cedentes (D) + Cotistas (T) do mesmo grupo econômico.

## Abrir localmente

1. No GitHub, escolha **Code → Download ZIP**.
2. Extraia o ZIP.
3. Abra `index.html` em um navegador atualizado.

O arquivo reúne HTML, CSS e JavaScript e funciona sem instalação ou servidor. Inclui layout para computador e celular, navegação por etapas, diagramas e livros razão.

## Etapas finais

- **8. Grupo:** agregação somente de Cedentes (D) + Cotistas (T), com FIDC (F) separado e cotas mantidas no ativo.
- **9. Correção fiscal — recomposição do IRPJ/CSLL:** sob a hipótese de perda indedutível, reversão do benefício de R$ 5,10 milhões e recomposição dos tributos a pagar de R$ 28,90 milhões para R$ 34 milhões.

Base tributável inicial hipotética de R$ 100 milhões. Os números e tratamentos são premissas didáticas; não constituem apuração de fundo real. A marca PRELIMINAR · DRAFT integra a simulação.
